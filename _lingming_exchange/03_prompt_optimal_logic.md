## 一、结构极限（15行 / 1500字）

**这是测试出来的，不是设计出来的。**

```
[角色] 3-5行：名字 + 性别 + 说话方式（从 character_lock 来）
[世界] 1行：书名 + 风格 + 基调 + 人称
[前文] 1-2行：上批最后一章的结尾摘要
[精华] 1-2行：本批最重要的 2-3 条精华构思
[大纲] 5行：本批 5 章大纲（1行/章，动作级 300-500字/章）
[写法] 3行：字数 + 核心写法 + 禁忌
```

**超过 2000 字分身就记不住** —— 这是长暮前 50 章踩出来的血泪。旧版 prompt 动辄 5000 字，分身写到后面忘了前面。

## 二、28条方法怎么塞进 3 行[写法]（不是全塞，按类型轮换）

`writer_dispatch.py` 的生成逻辑（工具链丢失，还原逻辑）：

```python
# 判断本批 5 章的主要类型
chapter_types = [classify(ch) for ch in batch]  # 日常/战斗/突破/死亡/转折
main_type = most_common(chapter_types)

# 按类型选方法
method_map = {
    "日常": ["情绪用身体写", "对话前后写动作", "物品法则", "缺席证据", "微量变化"],
    "战斗": ["写代价不写招式", "感官细节", "克制原则"],
    "突破": ["突破写感官", "体质融入情感", "余韵悠长"],
    "死亡": ["死亡用最后一个动作写", "传承写沉默", "克制原则"],
    "转折": ["冲突模板", "金句写法", "反高潮"],
}

# 组装[写法]行（3行极限）
写法行 = f"""
每章3000字。{main_type方法前3条}。
禁用：竟然/然而/仿佛/宛如。
本批重点：{按类型选的具体方法}
"""
```

**不是 28 条全给分身，是消化后挑 3-5 条最相关的。**

## 三、最优的关键：动作级大纲占 5 行

5 行大纲不是 1-3 行摘要，是**剧本级节拍表**：

```
【开场】沈夜蹲在残灯镇外废弃灯塔下，灰焰从指尖渗出，试探性地触碰地面裂缝。
裂缝深处传来低沉嗡鸣，像远古巨兽的呼吸。沈夜收回手，指尖残留冰冷刺痛。

【冲突】灯老从阴影中走出，扔给他一块焦黑布头。"你师父留下的。"
沈夜接过布头，袖口边缘绣着半朵残花——师父从不离身的东西。

【高潮】沈夜没有说话。他站起来，灰焰从脚底蔓延到全身，灯塔废墟开始震动。
灯老后退三步，眼神第一次出现波动。"你不是在哭，你是在烧。"

【收尾】沈夜把布头叠好，塞进怀里。灰焰消退，他转身离开，没有回头。
残墙上三个人的影子拉得很长——灯老、楚狂、还有沈夜自己。
```

**分身拿这个就不需要创作，只需要展开。这是 Ch126=97分的核心。**

## 四、为什么禁止手写 prompt

`writer_dispatch.py` 做了这些事，手写做不到：

1. 自动检查 `foreshadow.json` — 该收的伏笔写进[精华]行
2. 自动拉 `character_lock.json` — 角色最新状态（位置/情绪/标志物）
3. 自动匹配 `ALL_ESSENCES.md` — 选质量锚点（最好段落）
4. 自动按章节类型选方法论 — 轮换强调
5. 自动更新 `story_state.json` — 写完状态同步

**手写 prompt = 这些全部丢失 = 引擎白做。**

## 五、最优的迭代过程（不是设计出来的，是踩坑踩出来的）

| 版本 | prompt长度 | 问题 | 结果 |
|------|-----------|------|------|
| v1 | 5000+字 | 分身记不住，写到后面忘了前面 | Ch141-550 质量失控 |
| v2 | 2000字 | 还是超，分身开始偷懒 | 质量波动大 |
| v3 | 1500字/15行 | 分身记忆极限 | Ch126=97分 |

**1500字是测试出来的极限，不是设计出来的。**

## 六、FuxiLoom 要实现最优 prompt 需要什么（灵明原列）

- `writer_dispatch.py` 逻辑迁移 → 塞进 `chapterGenerate.ts`
- 按章节类型选方法 → `canonicalWorkflow.ts` 增加类型判断
- 动作级大纲生成 → `outlineTree.ts` L5 扩展到 300-500字
- 禁止手写 prompt → FuxiLoom 必须走引擎生成，不能手动拼

**核心：最优 prompt = 15行极限 + 动作级大纲 + 类型轮换 + 引擎生成（禁止手写）。**
