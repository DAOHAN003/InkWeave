# 万象 2.0 · 技术讲解

> 一个「活世界生成系统」（Living World Generation System）：给定一个种子，确定性地产出一个会自己演化、守恒、有因果、可逐帧复现的虚拟世界。
>
> **产品定位**：万象是**确定性世界模拟 / 可实验引擎**——世界本身（运行态、可观测、可对比、可分支、守守恒律）才是产物，散文/看板/导出只是世界的可读视图。护城河是「确定性可复现 + 可对比(diff/fork) + 守恒可信 + agent 涌现」，而不是「问一句答一段」的生成器。

---

## 一、整体形态：纯 Rust workspace，零 Python 依赖

万象 2.0 是 7 个纯 Rust crate 组成的 workspace（另有保留的 `mind_core` 作参考，697 测试，不参与运行时）：

| crate | 职责 |
|-------|------|
| `wanxiang_types` | 领域模型：实体/事件/规则/因果/蝴蝶效应/ECS 组件 + **中央配置 `config` 模块** |
| `wanxiang_core` | 编排内核：agent_system / orchestrator / subsystem_adapter / persistence |
| `wanxiang_brain` | NPC 认知：情感/五行/意识环/梦/洞察/元认知/FEP 预测环路 |
| `wanxiang_evolution` | 演化：基因组/健康/学习/选择/策略/统一演化 |
| `wanxiang_world` | **世界模拟器主体**：8 层 + 选择 + 社会 + 事件引擎 + 守恒律 + spawn |
| `wanxiang_engine` | 回放引擎（replay / 检查点重放） |
| `wanxiang_cli` | 命令行入口 |

迁移收口后 Python 栈已完全退役，唯一运行时是 Rust。测试 **174 全过**（types 17 + core 2 + brain 83 + engine 7 + sdk 4 + cli 1 + world 60；`cargo test --workspace` 实测，2026-07-12）。

## 二、核心：WorldSimulator 的 tick 主循环

`WorldSimulator::new_with_seed(rules, seed)` **构造即生成世界**（用盐值子流 spawn 初始世界，调用方无需手动 spawn）。之后每次 `tick()` 顺序驱动 **8 层** + **3 个引擎**：

1. **规则层** RulesLayer — 五行相生相克、季节、纪元推进、因果引擎
2. **物质层** MatterLayer — 环境能量、灵气密度
3. **生命层** LifeLayer — 生态健康、生物多样性、捕食平衡（由「世界能否支付能量」涌现）
4. **角色层** CharactersLayer — NPC 决策，路由到 FEP 预测环路
5. **社会层** SocietyLayer — 社交张力、文化多样性、贸易活跃度
6. **文明层** CivilizationLayer — 技术等级、文明分、历史快照
7. **灵性层** SpiritLayer — 灵气、业力、天道意志、天劫概率
8. **数学层** MathLayer — 世界熵、复杂度、涌现潜力

叠加三个引擎：**自然选择**（多层级）、**社会系统**（贸易/外交/有因之战）、**事件引擎**（随机事件 + 蝴蝶效应级联）。

---

## 三、四条统一法则（第一性原理地基）

1. **守恒律** — 物质 + 能量 + 信息 + 熵汇四池之和恒守恒，drift ≈ 0（见下）。
2. **自由能最小化（FEP）** — 每个 NPC 持独立预测环路，信念跨 tick 持续，最小化预测误差驱动决策（取代硬编码 if-else 行为树）。
3. **多层级选择（开放式进化，P5）** — 个体层（适应度淘汰）/ 群体层（弱势力吞并）/ 种群层（生育耦合能量丰度，围绕承载量自调节）/ 文化层（周期性注入新技艺/新势力抗收敛）。世界真演化，非静止均衡。
4. **数据导向纯核（P4）** — 账本状态 = 纯函数(初始, `ConservationOp` 流)，事件溯源，可 `reconstruct` 重建。

---

## 四、第一条统一法则：守恒律（Conservation）

世界的所有实体变化都经 `ConservationLedger` 的 `create` / `dissipate` / `transfer` 三原语路由，使 **物质 + 能量 + 信息 + 熵汇** 四池之和恒守恒：

- 创生（新生角色、新技艺）→ `create`，由熵汇支付（熵转负）
- 死亡/天灾 → `dissipate`，能量回归熵汇
- 贸易/掠夺 → `transfer`，池间再分配（Σ 不变）

每 tick 末观测 `world_conserved_quantity` 并 `reconcile` 对账，使 **drift ≈ 0**。这是复现契约之上的第一性原理地基——不是手调平衡，而是让守恒律自然收口。

---

## 五、确定性契约（P0 / P2 复现）

**同 seed → 逐帧字节级复现**，跨进程一致。实现要点：

- **双 RNG 子流**：tick 主 RNG = `StdRng::seed_from_u64(seed)`；spawn 子流 = `seed ^ SPAWN_STREAM_SALT`。两流独立，互不相关。
- **遍历集合时抽 rng，一律先转排序 `Vec`**。绝不用 `HashSet`/`HashMap` 迭代序抽 rng——否则同进程内稳定、跨进程发散（Rust 默认 Hasher 每进程盐值不同）。
- **确定性 id**：事件 `evt_{tick}_{fnv1a(desc)}`、角色 `char_new_{tick}_{bidx}`、势力 `fac_emerge_{tick}`，禁 UUID / SystemTime。
- **事件只在外层统一 log**：`simulator.tick()` 末尾统一记录；`butterfly_effect`/`selection`/`societal` 内部不得再 log（重复记录会改变 rng 路径）。

## 六、真实性升级（Batch 1–4）

- **Batch 1 · ECS 地基** — `Entity` + `ComponentStore` + `World`，组件化角色/势力/家族/贸易/外交/战争，所有迭代按 Entity 字典序有序返回。
- **Batch 2 · 家族血缘 + 技艺树** — 每势力立始祖家族，血脉人格跨代遗传（微突变）；确定性技艺树有前置依赖与扩散；`diffuse_tech` 排序 Vec 遍历消除跨进程随机性。
- **Batch 3 · 贸易网络 + 势力外交 + 有因之战** — 贸易互惠度累积；外交状态由意识形态/领土重叠/贸易互惠/战争状态共同驱动；战争带 6 种导火索，真实伤亡+掠夺+夺地+吞并；`prune_orphans` 清理吞并后孤儿引用。
- **Batch 4 · 叙事生成 + 事件去重** — 从事件流提炼结构化编年史（按时代分章）；事件只在外层统一 log，避免重复记录改变 rng 路径；`EventImportance` 派生 `Ord` 供叙事排序。

## 七、P1 代理因果闭环（NPC 进入因果链）

源码核对发现 NPC 的 FEP 决策曾被 `simulator` 丢弃（`_decisions`），agent 未进入因果链。收口三处：

- **P1-a** `CharactersLayer::decision_events()`：把有对外动作的决策映射为事件并入主事件流（不改守恒量、确定性）。
- **P1-b** `CharactersLayer::apply_decision_effects()`：让「耗能型」决策经 `ledger.dissipate(Energy)` 削减角色 `power_value`，真实改变世界状态且 `drift≈0`。
- **P1-c** `CharactersLayer::deep_cognition()`：激活每 NPC 深层认知子系统（梦境整合 / 顿悟催化），刻意**绕过 `NPCBrain::full_cycle` 的 `thread_rng` 非确定性路径**，直接驱动两个纯函数子系统（零 rng）。

深层认知以 `config::layers::CHAR_DEEP_COGNITION` 编译期开关**默认关闭**（守护测试契约与确定性）；开启后双 seed 跨进程一致、漂移 0.0000。至此 NPC 从「旁观者」变为「决策→事件→改状态→内在认知涌现」的完整主动 agent。

## 八、P3 统一大脑收口（LivingBrain 接入 tick）

- **问题**：此前 NPC 丰富认知（意识环/量子神经元/梦/顿悟）休眠——`NPCBrain::full_cycle` 等四处用 `thread_rng`/`from_entropy` 非确定性，绝不能落入 tick。
- **收口（确定性化）**：四处 rng 全部改为**调用方注入式 `&mut StdRng`**（与 `decide_via_fep` 同款纪律）；`LivingBrain::new` 全程零 `thread_rng`，跨进程构造逐字节一致。
- **接入 tick（gated）**：`CharactersLayer.brains` 升级为完整 `LivingBrain`；`rich_cognition()` 在 `CHAR_RICH_COGNITION == true` 时由 `tick` 调用，按 `character_id` 排序遍历共享 tick rng，驱动确定性 `full_cycle`，产出可观测认知事件（「灵台澄明」顿悟）。
- **契约零风险**：`rich_cognition` 只产事件、不动 `power_value`/账本 → `drift≈0`；默认关闭零事件增量。开启后双 seed 跨进程一致、漂移 0.0000。

## 九、P2 产出层（可读导出，全部不绑定世界模板）

用户硬约束：**导出层绝不写 `match WorldType` 题材分支、不假定任何题材取值**，由数据驱动、非代码模板。

- **P2-1 · 散文叙事**（`--prose`）：`generate_prose()` 把事件流+实体快照编织为章节体散文；`name_index` 持久登记使已消失实体仍可解析名称；排除遥测事件、洗净 `Death`/外交内部机制泄漏；纯函数、跨进程逐字节确定。
- **P2-2 · 通用 8-JSON 导出**（`--export <dir>`）：`world_export` 把世界状态镜像为 8 份 JSON（entities/factions/events/eras/skills/wars/resources/rules）；HashMap 经排序后序列化，同 seed 逐字节一致；纯函数、零副作用。
- **P2-3 · Web 编年史看板**（`--dashboard <dir>`）：先写 8 份 JSON，再内联进自包含 `index.html`（双击即开、无需服务器）；JS 只消费通用形状，绝无题材分支；含守恒律仪表/时代时间线/势力兴衰/事件流/战争/技艺树。

## 十、P4 工程化（Save/Load · diff · scan）

核心洞察：万象世界是 `(seed, rules)` 的纯函数，故「存档」只需持久化 `(seed, tick, rules)` 三者，「读档」由 `new_with_seed` 重建 + 确定性重放前 `tick` 步，逐字节恢复完整世界。

- **P4-a · 检查点**（`--save <path>` / `--load <path>`）：`Checkpoint{seed,tick,rules}` + `restore_world`（重放）；`WorldRules` 及其子类型已 `derive(Serialize, Deserialize)`，serde 面**只有 `WorldRules` 一个类型**，零新序列化面；重放 = 复现，与「同 seed 直接跑到同 tick」逐字节等价。
- **P4-b · 世界 diff**（`--diff <a> <b>`）：纯函数 `diff_world(a, b)`，维度含规则是否不同、守恒四池 Δ、实体计数 Δ、按索引对齐事件流找**首分歧 tick**；只读、零 rng、不破坏契约。
- **P4-c · 规则扫描矩阵**（`--scan`）：固定 seed+ticks，对 11 个候选字段做单因子强扰动后 diff 基线，量化「哪个 `WorldRules` 字段真正撼动世界」；纯函数、零 rng。

> **P4 暴露的真实特性（重要）**：`--diff` / `--scan` 实测证明——当前 `world_type`（题材）与 `energy_density`/`order_level`/`chaos_level`/`life_fertility`/`resource_abundance` 等通用标量字段在模拟动力学中是**「标签性」**的（同 seed 换题材世界逐字节相同，仅规则元数据不同）；真正影响世界的是 `max_entities`/`death_protection_init` 等 spawn 相关字段。这直接标出 **P3 题材扩展（GenreKit）的接线缺口**（见第十二节）。

## 十一、P5 World Lab（观赏 + 经济标定 + 实验三合一产品壳）

万象产物是**数据**——世界状态/事件流/实体/守恒量/叙事素材，供下游消费（游戏后端 / 写小说基座）。World Lab 把能力合成自包含产品壳：

- **经济标定** `economy.rs`：纯函数 `calibrate_economy` 聚合贸易网络密度、互惠度、累计贸易量、资源总量、势力财富基尼系数、能量池、经济活跃度复合指数——使「什么条件下经济涌现」可量化（下游「给我一个自带繁荣贸易网的世界」的钩子）。
- **World Lab HTML** `world_lab.html`：自包含页面（JSON 内联），三区合一——观赏区（守恒律仪表/时代时间线/势力兴衰/事件流）+ 经济标定区 + 实验区（规则扫描矩阵）；模板无关（不 match `WorldType`）。
- **CLI** `--lab <dir>`：写 8 份通用 JSON + economy.json + scan.json + index.html，scan_ticks = min(ticks, 40)。
