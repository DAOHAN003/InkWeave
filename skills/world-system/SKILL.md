# 万象世界演化系统

## 12种世界类型

| 类型 | 能量体系 | 特色 | 战斗概率 |
|------|---------|------|---------|
| 仙侠 | 灵气 | 宗门/天劫/修炼 | 15% |
| 武侠 | 内力 | 江湖/门派/侠义 | 20% |
| 玄幻 | 斗气 | 血脉/家族/天赋 | 25% |
| 奇幻 | 魔力 | 公会/冒险/怪物 | 18% |
| 科幻 | 能量 | 飞船/星际/AI | 10% |
| 都市 | 无 | 公司/社交/经济 | 5% |
| 历史 | 无 | 朝代/军队/天骄 | 12% |
| 军事 | 无 | 战争/军队/战略 | 30% |
| 末日 | 辐射 | 废墟/变异/生存 | 20% |
| 悬疑 | 无 | 密室/线索/推理 | 5% |
| 言情 | 无 | 日常/心动/遗憾 | 2% |
| 闻道仙侠 | 声音/灵气 | 万物有声/闻道体系 | 12% |

## 37维度能力概览

### 角色维度（11项）
- 记忆系统（积累经历，影响决策）
- 情绪系统（5维：仇恨/悲伤/兴奋/恐惧/好奇）
- 记忆驱动决策（记忆→情绪→行动）
- 角色回忆（想起旧事，触发新行动）
- 个人习惯/随身物件/身体特征（伤疤/白发）
- 饥饿/疲劳/受伤分阶段恢复
- 性格系统（Big Five五维人格）
- 个性化目标（29种，性格驱动）
- 功法/法宝系统
- 角色迁移（有距离、有旅行时间）
- 弧光时刻（绝境逆袭/大彻大悟/牺牲救人）

### 关系维度（7项）
- 7种关系类型（盟友/挚友/敌人/仇人/恋人/师/徒）
- 关系自然衰减（不见面就变淡）
- 误会/和解机制
- 恩怨永久记忆
- 角色间化学反应（性格冲突）
- 深度互动（切磋/交易/传授/对话）
- 关系网络演化

### 世界维度（9项）
- 四季循环（春集市/夏比武/秋考核/冬祈福）
- 生态系统（食物链/资源枯竭/灵兽出没）
- 天气影响（中暑/受寒/雨雪减速）
- 势力系统（崛起/合并/分裂/消亡/战争）
- 因果链（5层深度）
- 世界大事件连锁反应
- 历史回响（古碑/封印/传说）
- 悬念/伏笔
- 时间跳跃标记

### 叙事维度（5项）
- 内心独白
- 遗言系统
- 场景描写（八维度）
- 角色对话
- 多线叙事

### 质量维度（5项）
- 100%唯一描述（零重复）
- 99%描述≥50字
- 事件评分系统（S/A/B/C/D）
- 描述去重机制
- 性格着色+环境感知

## 核心设计原则

1. **模板不是写死的字符串列表**——是规则+概率+生成器
2. **力量体系可自动生成**——设fixed_levels=None，引擎根据naming_style自动生成境界名
3. **5%概率自动碰撞出混血体系**——仙侠×科幻="量子修仙"
4. **万象不创造，万象只演化**——模拟世界、输出数据、提供规则和模板
5. **子系统独立可选**——每个子系统通过_AVAILABLE标志管理，失败不影响主引擎
6. **学习系统**——从历史数据中学习，越跑越聪明

## 世界构建指令

创建世界时必须指定：
- world_type：12种类型之一
- seed：随机种子（换seed换世界）
- num_characters：角色数量
- num_locations：地点数量

构建世界时必须考虑：
1. 能量体系与世界类型匹配
2. 战斗概率与世界基调一致
3. 势力结构合理分布
4. 四季循环/天气系统根据世界类型设定
5. 角色目标体系与世界特色结合
6. 因果链深度与叙事需求匹配

模板包含：world_rules（世界规则）+ power_system（力量体系）+ event_weights（事件权重）+ naming（命名风格）+ culture（文化设定）

## 执行指令

构建世界时必须：
- 选择匹配题材的世界类型，明确能量体系和战斗概率
- 角色设计必须包含：记忆系统、情绪系统、性格、目标、功法/法宝
- 关系网：至少包含7种关系类型中的3种
- 世界维度：四季循环、生态系统、势力系统、因果链必须激活
- 模板使用规则+概率+生成器模式，不写死字符串
- 力量体系优先自动生成，必要时手动指定fixed_levels
- 确保37维度中角色/关系/世界/叙事/质量五大类均有覆盖
- 混血体系（5%概率自动碰撞）可用于创新世界设定
- 子系统通过_AVAILABLE标志管理，可选模块失败不影响主引擎
