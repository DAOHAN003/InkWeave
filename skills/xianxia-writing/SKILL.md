# 仙侠玄幻写作指南

## 9大修炼境界体系

**凡人 → 练气（1-9层）→ 筑基（1-9层）→ 金丹（1-9层）→ 元婴（1-9层）→ 化神（1-9层）→ 合体（1-9层）→ 渡劫（1-9层）→ 大乘（1-9层）→ 飞升**

每个大境界突破=一个大爽点，每个小层突破=一个小爽点。主角比同龄人快3-5个大境界=持续碾压感。

### 境界核心特征

- **练气期**：感知灵气，初步修炼，战斗力弱
- **筑基期**：奠定根基，可御剑飞行，开始接触战斗
- **金丹期**：结成金丹，寿元大增，战力质变
- **元婴期**：元婴出窍，可夺舍重生，一方强者
- **化神期**：神识化形，掌控天地灵气
- **合体期**：法身合一，近乎无敌
- **渡劫期**：承受天劫，突破即成仙
- **大乘期**：超脱凡俗，掌控一方天地
- **飞升**：进入仙界/神界，开启全新篇章

## 战力辅助系统

1. **丹药系统**——回复/增幅/突破（炼丹是持续爽点来源）
2. **法宝系统**——攻击/防御/辅助（收集法宝=捡宝爽点）
3. **功法系统**——基础/高级/天级/圣级/神级（功法升级=战力暴涨）
4. **血脉系统**——普通/变异/远古/混沌（血脉觉醒=身份揭秘）

## 5种热门金手指设计

### 1. 混沌鼎/太古炉——炼丹无敌+炼化万物
- 爽点：别人炼废的丹你一炉成，还多出三颗
- 适用：炼丹流、炼器流主角

### 2. 天道之眼/鉴宝瞳——看穿一切
- 爽点：拍卖会上别人出天价买废物，你花一文钱捡到神器
- 适用：鉴宝流、捡漏流主角

### 3. 轮回重生——带着前世记忆和修为重生
- 爽点：知道所有机缘在哪/知道谁会背叛/提前布局
- 适用：重生流、先知流主角
- **推荐组合**：轮回重生+混沌体质=先知+碾压

### 4. 吞噬体质——吞噬别人的修为/血脉/功法
- 爽点：打败对手后还能吸收对方实力
- 适用：吞噬流、收割流主角

### 5. 时间加速空间——外面1天=里面1年
- 爽点：闭关3天出来实力暴涨，别人以为你开挂
- 适用：闭关流、速通流主角

## 势力格局设计

### 三层势力结构
- **小世界**：宗门（天玄宗/剑灵宗/丹霞宗）+ 家族（陈家/赵家/王家）
- **中世界**：帝国/圣地/隐世势力
- **大世界**：上界/仙界/神界

主角路线：宗门内弟子 → 宗门天才 → 参加大比 → 进入圣地 → 飞升上界

每个层级都有：新敌人（更强天才）+ 新机缘（更强功法/法宝）+ 新美女 + 新打脸对象

## 开头设计公式

### 第1章公式
- 开篇100字：主角在最惨的时刻（被逐出宗门/被退婚/被杀）
- 200字：重生/觉醒（回到过去/金手指激活）
- 500字：第一个爽点（用先知躲过陷害/用新能力碾压欺负自己的人）
- 章末：更大的机会出现（发现一个前世不知道的机缘）

### 前3章必须完成
- 第1章：重生/觉醒+第一个小打脸
- 第2章：金手指规则+第一个机缘（找到前世错过的宝物）
- 第3章：第一个正式打脸（碾压曾经看不起自己的天才）+宗门试炼开始

## 战斗描写核心

**感官密集写法**（不写"一剑劈出"，写）：
"剑锋切入空气的一瞬间，他听见了风被撕裂的声音。不是呼啸，是嘶——像布被扯开。剑尖的寒气从手腕传到肩膀，冷的，麻的。"

**突破描写写法**（不写"他突破了练气三层"，写）：
"丹田里的灵气像一锅沸腾的水，从下往上涌。热的。烫的。从丹田烫到胸口，从胸口烫到喉咙。他咬住牙，牙根发酸。然后——'咔'。像什么东西碎了。不是碎，是开了。一扇门，在身体里面，开了。"

## 执行指令

写作时必须：
- 境界体系清晰：9大境界×9小层，每个突破都是爽点
- 战斗/突破/修炼写感官细节和身体感受
- 金手指必须有独特爽点机制，推荐轮回重生+混沌体质组合
- 势力分三层结构（宗门→圣地→上界），每层配新敌人/新机缘
- 开头3章必须完成：重生+小打脸+金手指说明+机缘+正式打脸
- 丹药/法宝/功法/血脉四大系统贯穿全文，持续制造爽点
- 主角比同龄人快3-5个大境界，持续碾压感
- 拒绝"一剑劈出"式描写，用感官密集写法
- 炼丹/捡宝/鉴宝等场景要写出具体细节，不笼统
