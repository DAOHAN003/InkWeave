# 番茄爆款爽文写作指南

## 10种爽点类型（每章至少1个）

1. **打脸**——看不起主角的人被现实打脸（最爽，核心爽点）
2. **逆袭**——从最底层一步步碾压（持续爽感）
3. **装逼**——扮猪吃老虎，关键时刻亮身份
4. **升级**——实力突破/获得新能力/解锁新技能
5. **捡宝**——获得神器/秘籍/传承/系统奖励
6. **救美**——在绝境中救下美女/获得好感
7. **碾压**——以绝对实力碾压对手（读者代入感最强）
8. **复仇**——被欺负后强势回击
9. **震惊**——所有人被主角实力/身份震惊
10. **认主**——神兽/神器/大佬主动认主角

## 3种钩子设计（章末必用）

1. **悬念型**——"门外站着一个人。那个人，不应该出现在这里。"
2. **危机型**——"他的灵力，在这一刻，彻底枯竭了。"
3. **反转型**——"他笑了。因为他等的，就是这一刻。"

**执行规则**：每章最后3行必须有钩子，让读者忍不住翻下一章。

## 金手指设定原则

1. **有限制**——不能无敌，要有代价
2. **可升级**——跟主角一起成长
3. **有独特性**——别人没有的
4. **能制造爽点**——每次使用都有爽感

好的金手指：系统/鉴宝之眼/时间回溯/读心术/炼丹天赋
差的金手指：直接无敌/一拳打爆星球（没有成长空间）

## 黄金3章公式

### 第1章必须完成
- 前100字：制造冲突（主角被欺负/被看不起/遭遇危机）
- 前500字：金手指激活（系统觉醒/获得传承/重生回来）
- 前1000字：第一个小爽点（用金手指化解危机/打脸一个小人物）
- 章末：更大的危机或更大的机会（钩子）

公式：**惨（被欺负）→ 转（金手指来了）→ 爽（小试牛刀）→ 钩（更大的事来了）**

### 前3章必须完成
- 第1章：主角出场+金手指激活+第一个爽点
- 第2章：金手指的规则说明+第二个爽点（更大）
- 第3章：主线冲突建立+第一个打脸场景+长线钩子

3章内必须让读者知道：
1. 主角是谁（身份/处境）
2. 金手指是什么（能力/限制）
3. 主线目标是什么（要做什么）
4. 第一个敌人是谁（冲突对象）

## 节奏控制公式

- **每章**（2000-3000字）：至少1个爽点+1个钩子
- **每5章**：1个小高潮（打脸一个小反派）
- **每20章**：1个中高潮（解决一个大危机/升一个大级）
- **每50章**：1个大高潮（打脸一个大反派/身份大揭露）
- **每100章**：1个超级高潮（逆天改命/碾压boss）

低谷规则：
- 低谷不超过2章（读者耐心有限）
- 低谷中也要有小爽点（不能纯惨）
- 低谷后的爽点要加倍（压得越低弹得越高）

## 去AI味（爽文版）

爽文的去AI味：要爽/要快/要直接/要装逼

1. **对话要短要狠**——"你算什么东西？"（不要"他感到对方的实力不容小觑"）
2. **打脸要具体**——写脸的表情变化（不要"众人震惊"）
3. **升级要有仪式感**——写突破的身体感受（不要"他的实力提升了"）
4. **装逼要有反差**——先被看不起→再一击碾压

## 爆款推荐方向

- **都市系统流**——现代背景好写+系统提供结构化升级（热度最高）
- **玄幻升级**——战斗场景模板化+等级体系清晰
- **重生逆袭**——主角知道未来走向好安排剧情
- **赘婿打脸**——套路固定+打脸场景好写
- **神医/神豪**——场景丰富+爽点密集

## 执行指令

写作时必须：
- 每章至少1个爽点+1个章末钩子（悬念/危机/反转）
- 前3章必须完成：主角出场+金手指+第一个爽点+主线冲突+长线钩子
- 对话短、狠、直接，符合爽文节奏
- 打脸写具体表情变化，碾压有反差感
- 升级写身体感受和仪式感，不写"他变强了"
- 低谷不超2章且有小爽点，低谷后爽点加倍
- 每5章小高潮、每20章中高潮、每50章大高潮
- 金手指必须有限制+可升级+独特性+能制造爽点
- 避免AI味：不写书面化对话、不写笼统的"众人震惊"
