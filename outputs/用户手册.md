# FuxiLoom 用户手册

FuxiLoom 是基于**确定性世界模拟（万象引擎）**的 AI 小说创作工具。它先把你的世界观、角色、事件演进成一份「权威剧情源」，再由 LLM 把演化戏剧化成文——世界数据驱动正文，而非纯靠提示词。

## 一、启动与界面

- **启动**：双击 `FuxiLoom Novel Writer Ai.exe`，或通过 NSIS 安装后在开始菜单启动。首次启动会有欢迎引导。
- **三栏布局**：
  - 左栏：作品资源（新建 / 切换作品、卷章树）。
  - 中栏：卷 / 章节树（可拖拽宽）。
  - 右主区：写作编辑器 / 大纲树 / 世界构建 / 经验库 / 创作流水线（顶栏切换）。
- **顶栏**：作品名 · 主视图切换 · 设置 · **运行日志** · 主题色点。
- **底栏**：字数 · 模型状态 · 自动保存 · 专注模式。

## 二、首次配置（必做）

1. 打开「设置中心」→「模型设置」：填写 API Key 并点**保存配置**（写入 `localStorage`，这是 AI 实际读取处）。
   - 写作温度建议 0.8–0.9，编辑 0.3–0.5。
   - 如需语义前情召回，配置「嵌入模型」Key。
2. 本地模型可选：Ollama（如 `qwen3:14b` / `qwen3.6:27b-a3b`，需本机已装）。

## 三、核心工作流

1. **新建作品** → 选题材（仙侠 / 科幻 / 都市 / 历史 / 西幻 / 自定义，未知一律中性）。
2. **世界构建**：在「世界构建」视图录入设定、角色、伏笔、时间线、角色弧。
3. **角色锁**：在角色编辑里填「口癖」与「禁用言行」——生成时自动注入，并由 OOC 守门拦截偏离。
4. **写本章**：选「写作」视图，AI 写本章会从世界模拟取权威简报 → 自检（OOC / 扫敏）→ 去 AI 味（repairLoop）→ RAG 前情 → 落盘。
5. **连写 / 长篇**：「创作流水线」支持极简 / 连写，每章落自己章节；百万字长篇用卷/章节/时间线/EPUB 管理。
6. **自检报告**：写完后看 AI 味评分、节奏张力、文风调制三份报告；Rubric 违规红标，可一键修复。
7. **导出**：「设置 → 导出」生成 EPUB。

## 四、关键能力说明

- **万象世界模拟**：确定性推进事件、角色心智、经济；世界实例用完即销毁，避免泄漏。
- **NMM 情感记忆**：自动给前情打情感标签（红涨 / 绿跌约定不适用此处，按情感极性着色），前情召回更贴合情绪线。
- **RAG 前情**：语义 / 词袋双模式召回，阈值 + 多样性 + 切块优化，减少低分噪声。
- **跨章账本**：归一化匹配事实，防止设定前后矛盾。
- **LNN + Rubric**：16 维文本特征 → 去 AI 味评分 / 节奏监督 / 文风调制。

## 五、数据安全

- 正文、风格样本、世界追踪默认存 `localStorage`；每次保存额外落文件快照到 `app_data_dir/fx_backup/`（保留最近 10 份）。
- 启动若发现 `localStorage` 损坏，自动从文件备份恢复并提示。
- 想要更稳：定期用「数据备份 / 恢复」面板手动导出快照。

## 六、故障排查

- **写不出来 / 报错**：先确认模型 Key 已「保存配置」（不是「配置补全」面板那个只读预览框）。
- **卡顿 / 异常**：点顶栏「运行日志」查看 `app.log`；崩溃信息在 `panic.log`。把相关行发回即可定位。
- **丢稿迹象**：立即去「数据备份 / 恢复」从快照恢复；不要清空浏览器缓存。
- **白屏**：通常是模块加载期抛错，页面会显示错误堆栈，截图发回。

## 七、命令行（高级）

- `scripts/fuxi-bridge.ts`（需 Node + tsx）：`npx tsx scripts/fuxi-bridge.ts <command>`，含 `emotion` 等子命令，供外部脚本桥接。
- HTTP API（`api_server`）：`/wanxiang/create`、`/wanxiang/step`、`/wanxiang/:id/info`，供 OpenClaw 等外部系统接入。
