# 本地模型跑通卡片（零 API Key 版）

> 目标：不花一分钱、不联网调用云端，让 FuxiLoom 完整跑起来（写作 + 语义前情召回）。
> 代码侧已全部就绪（后端探测按钮 / 模型点选 / scope 修复）。本卡片只涉及真机操作。
> 适用 exe：`FuxiLoom Novel Writer Ai.exe`（2026-08-29 07:00 之后构建的版本）。

---

## 第 0 步：确认 Ollama（1 分钟）

PowerShell 或 CMD 执行：

```
ollama --version
```

- 有版本号 → 进第 1 步。
- 报"不是内部或外部命令" → 去 `https://ollama.com/download` 下载安装（Windows 版一路下一步），装完**重开终端**再执行上面命令。

## 第 1 步：拉两个模型（按网速 5-20 分钟）

```
ollama pull bge-m3
ollama pull qwen3:14b
```

- `bge-m3`（约 1.2GB）：嵌入模型，管「语义前情召回」。
- `qwen3:14b`（约 9.5GB）：写作主力。你的 RTX 3060（12GB）单卡就能跑，先求通再求好。

验证：

```
ollama list
```

输出里必须能看到 `bge-m3` 和 `qwen3:14b` 两个名字——**记下它们的确切写法**，第 3 步点选时以此为准。

## 第 2 步：FuxiLoom 里点三下（30 秒）

1. 双击 `D:\fork_FuxiLoom\src-tauri\target\release\FuxiLoom Novel Writer Ai.exe`
2. 顶栏 → **模型设置**，在「连接」区：
   - 点 **「一键 Ollama 本地」**（自动填 localhost:11434 + Ollama 后端 + API Key 留空）
   - 点 **「检测本地后端」** → 应显示绿色 **「已连接（N 个模型）」**
3. 下方出现**模型 chips**（你本机已拉的模型列表）→ 点 **`qwen3:14b`** 设为写作模型。

## 第 3 步：嵌入配置（20 秒）

同一面板滚到「语义嵌入（RAG 前情召回）」区：

1. 点 **「一键本地嵌入（Ollama bge-m3）」**（自动填 localhost:11434/v1 + bge-m3 + Key 留空）
2. 下方 chips 会**自动筛选出嵌入类模型** → 点 **`bge-m3`**
3. 状态应显示 **「语义嵌入已启用」**

最后点 **「保存配置」**（如果面板有该按钮），并确认底栏模型状态已更新。

## 第 4 步：两个判定点（判断真生效，不是看状态灯）

### 判定 A：写作通了
随便打开一章 → 「AI 写本章」→ 能出正文 = 写作链路通。

### 判定 B：语义召回真生效
写/打开一章，做一次**前情召回**，看面板上的召回方式标签：

- 显示 **「语义嵌入」** = bge-m3 真在干活 ✅
- 仍是 **「离线词向量」** = 配置没生效（见下方排查）

> 说明：离线词向量模式也能用（字面共现召回），但配好 bge-m3 后近义/改写的前情也能命中，长篇连贯性上一个台阶。

## 卡住了？按这个排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 「检测本地后端」显示**连接超时** | Ollama 服务没在跑 | 任务栏找 Ollama 图标；没有就执行 `ollama serve` 或重装 |
| 显示**无法连接** | 端口不对/防火墙 | 默认 `11434`；执行 `curl.exe http://localhost:11434/api/tags` 能看到 JSON 就说明服务正常 |
| 「已连接」但 chips 里**没有** qwen3:14b | 模型还没拉完 | 回第 1 步看 `ollama list` |
| 召回标签一直是「离线词向量」 | 嵌入配置没保存，或 bge-m3 没拉成功 | 重做第 3 步；确认 `ollama list` 有 bge-m3 |
| AI 写本章报错 | 模型名和 `ollama list` 不一致 | chips 点选可避免手输错误；若手输过请核对 |
| 生成特别慢/爆显存 | 14B 对 12GB 卡偏满 | 正常现象（Q4 约 9.5GB + KV 缓存）；可先拉 `qwen3:8b`（约 5.5GB）求稳 |

**任何卡点**：顶栏「运行日志」→「复制全部」→ 发我。

---

## 为什么推荐 qwen3:14b 起步（而不是更大的）

| 模型 | Q4 显存 | 你的适配 |
|---|---|---|
| `qwen3:8b` | ~5.5GB | 最稳，速度快 |
| **`qwen3:14b`** | **~9.5GB** | **推荐起步：3060 单卡可跑，质量明显好于 8B** |
| `qwen3:32b` | ~20.5GB | 质量跃升，需双卡（5060Ti+3060 合力） |
| `qwen3.6:35b-a3b` | ~22-24GB | 项目预设默认值，MoE 速度快，但 Ollama 对 3.6 系有已知兼容坑 |

**原则：先用 14B 把整条链路跑通，再考虑换大模型提质量。** 流程通了换模型只是点一下 chips 的事。
