# FuxiLoom 真机验收清单（v5.3.2）

> 目的：在目标机器双击 `FuxiLoom Novel Writer Ai.exe`（或 NSIS 安装后启动）逐项核验功能一致性与稳定性。每一项「通过」需肉眼确认，未通过请记录现象并反馈。

## 0. 启动与基础
- [x] 双击 exe / 启动器，应用正常打开，不白屏、不闪退。✅ 2026-08-29 真机验收通过
- [x] 顶栏出现「运行日志」图标（文件图标），点击可打开日志面板（显示「暂无日志。」或已有条目）。✅
- [x] 底栏显示字数 / 模型状态 / 自动保存态。✅ 含「已保存 HH:MM:SS」实时时间戳

## 1. 数据安全（防丢稿）
- [x] 新建并编辑一个作品、写几章正文 → 关闭重开，正文仍在（`localStorage` 持久化生效）。✅ 236 字逐字完整（P0 外置存储恢复验证）
- [x] 打开「数据备份 / 恢复」面板（设置 → 备份），能看到自动快照；手动导出快照成功。✅ fx_backup 多时间戳快照；.fxnovel 导出成功（manifest+checksum）
- [ ] 模拟异常：删除 `localStorage`（DevTools → Application → Clear）→ 重启应用，应从 `app_data_dir/fx_backup/` 自动恢复（弹出恢复提示）。
- [x] 打开「运行日志」，确认保存类事件未出现 ERROR（如有 ERROR 记录其文本）。✅ 全程零 ERROR

## 2. 角色锁（声音一致性）
- [ ] 在角色编辑里给某角色填「口癖」与「禁用言行」。
- [ ] 跑 AI 写本章（勾「自检」）→ 自检报告「角色声音锁定」项定向修复串味 / 命中禁用言行。
- [ ] 正文里该角色口癖稳定出现、禁用言行不再出现。
- [ ] **角色成长轨迹注入（2026-09-16 新增）**：点「提取角色经历」为第 1、2 章各提取一次 → 设置库的角色卡应显示经历文本（不是原始 JSON）→ 写第 3 章时，正文行为应与前两章经历连贯。原缺陷：`storyArc` 写端存纯句子、读端 `JSON.parse` 后静默跳过，「角色成长轨迹」prompt **从未生效**（恒为空串），现已两端对齐。
- [ ] **注入完整性复验（2026-09-16 追加）**：分别用**极简/连写模式**与**六步管线**各写一章，确认两种模式下角色口癖/禁用言行都生效（此前声音锁定漏了叙述框架与融合步、成长弧光只进了降级路径）。判定口径：同一份角色设定，两种模式下的「听话程度」应无系统性差异。

## 3. NMM 情感 / 因果记忆
- [ ] 写几章情绪强烈的章节（喜怒哀惧交替）。
- [ ] 打开前情召回面板，确认 NMM 记忆带情感标签（红/绿/蓝等情感极性）。
- [ ] 长篇情绪前情召回稳定，未退化。

## 4. RAG 前情召回
- [ ] 配置嵌入 Key（模型设置 → 嵌入模型），用语义模式写长篇。
- [ ] 对比：低分噪声消失、关键前情命中更准（召回面板可看相似度）。

## 5. 跨章账本一致性（continuityLedger）
- [ ] 设定某事实（如「主角左眼有疤」），后续章节改写尝试颠覆 → 守门 / 账本提示冲突。
- [ ] 归一化匹配生效：同义表述（「他左眼有疤」/「左眼的疤痕」）被识别为同一事实。
- [ ] **设定一致性检测（2026-09-16 新增）**：第 1 章写「主角左眼有疤」并生成 → 第 2 章写「他左眼完好无疤」并生成 → 自检闭环应报「设定冲突」并定向改写；「世界守护」面板应显示「跨章设定一致性」区块及冲突条目。反例：「众人注意到他左眼的疤痕」不应误报。

## 6. 万象桥接（OpenClaw / HTTP）
> 应用启动后监听 `http://127.0.0.1:18791`。下面命令在**应用已打开**时执行；PowerShell 与 CMD 二选一，内容等价。

- [x] `GET /status` 返回 `ok:true` 且 `version` 为 `0.1.0`。✅ 实测 version=5.3.2（清单预期值过时，实际更新）
- [x] `POST /wanxiang/create` 返回真实 `world_id` 且 `info` 非空（不是 `{}`）。✅ world_id:1，characters:71/factions:6/conserved:true
- [x] `POST /wanxiang/step` 步进 5 tick 后 `info` 相对 create 时有变化（证明真接引擎，非 ok 占位）。✅ tick 0→1，events 0→146
- [x] `GET /wanxiang/1/info` 返回真实世界状态 + 最近事件。✅

判定标准：`/wanxiang/create` 的 `info` 必须是**非空对象**（含真实世界字段）；若返回 `{}` 或 `ok:true` 占位即说明桥接未接引擎，直接反馈。

## 7. 连写落章（worldDrive）

- [ ] 多章连续生成，章节序号、卷归属正确。

## 8. LNN + Rubric 三报告
- [ ] AI 写本章完成后，同时产出：AI 味评分报告、节奏张力监督报告、文风调制报告。
- [ ] Rubric 违规项在自检报告中以红标呈现，并可一键修复。
- [ ] **结果卡渲染（2026-09-16 新增）**：勾「自检」生成后，自检闭环面板应出现「LNN 三报告」卡——含 AI 味评分条（与阈值对比着色）、节奏张力 2 维、文风调制 8 维 delta、可折叠的 16 维特征明细。

## 9. 崩溃与日志
- [ ] 触发一个可恢复错误（如无效 API Key）→ 不白屏，日志面板出现 ERROR 记录，且提示可读。
- [ ] Rust 端崩溃（如有）写入 `app_data_dir/logs/panic.log`。
- [ ] **前端网络错误落盘（2026-09-16 新增）**：断网（或把模型 Base URL 指向不可达地址）后触发一次 AI 调用 → 「运行日志」面板应出现来源为 `fetch` 的 WARN/ERROR 记录（HTTP 非 2xx 记 WARN，连接失败记 ERROR）。这是原「前端网络错误不落盘 ❌」的复验项。
