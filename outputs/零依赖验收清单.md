## 先跑这个：命令行自检（30 秒，不用开 exe）

在项目目录执行（PowerShell 或 CMD 都行）：

```
npm run verify:offline
```

> 等价于 `npx tsx scripts/verify_offline_core.ts`。`tsx` 已声明为 devDependency（`^4.23.13`），`npm install` 后即可**离线**运行 —— 本清单验的就是「零依赖 / 可断网」，验证命令自身也不该依赖网络。（2026-09-16 修正：此前 `tsx` 未声明，`npx` 会临时联网拉包，与清单主旨矛盾。）
>
> **该步骤已接入 `npm run ci` 作为 `[8/8]`**（约 6 秒），此后不再需要人工单独跑 —— 一旦本地确定性能力被改坏，CI 会直接拦住。

## A 组：零依赖，现在立刻能验（不需任何模型 / Key / 联网）

### A1. 启动与基础
- [ ] 双击 `D:\fork_FuxiLoom\src-tauri\target\release\FuxiLoom Novel Writer Ai.exe`，应用正常打开、不白屏、不闪退。
- [ ] 顶栏有「运行日志」图标（文件图标），点击能打开日志面板。
- [ ] 底栏显示字数 / 模型状态 / 自动保存态。

### A2. LNN 三报告（纯本地，已实测可用）⭐
- [ ] 找一段**明显 AI 味**的文字（如"首先，值得注意的是…总的来说，这一情节发展不仅…")，跑 LNN 检测 → AI 味评分应**明显偏高**（参考值 ~0.89）。
- [ ] 找一段**真人味**的短句（如"他没说话，把刀插回鞘里。雪还在下。")→ 评分应**接近 0 或为负**（参考值 ~-0.01）。
- [ ] 三份报告（AI 味评分 / 节奏张力 / 文风调制）都出得来。

### A3. 前情召回（离线词向量模式）
- [ ] 写两章，其中一章埋一个具体细节（如"左眼的疤痕"），另一章提到它。
- [ ] 打开前情召回面板 → 标签应显示 **「离线词向量」**（未配嵌入模型时的默认回退）。
- [ ] 召回结果里能看到相关前情（字面共现能命中；近义/改写命中不了是正常的，配了 bge-m3 才会提升）。

### A4. 数据安全（防丢稿）⭐
- [ ] 新建作品、写几章正文 → 关闭应用重开，正文仍在。
- [ ] 打开「数据备份 / 恢复」面板，能看到自动快照。
- [ ] 手动导出一份快照成功。

### A5. 万象世界模拟（纯 Rust 确定性计算）
- [ ] 打开世界模拟相关面板，能推进世界（step），能看到事件产出。
- [ ] 同一 seed 重复推进，结果应一致（确定性）。

### A6. 角色锁守门 / 跨章账本（纯本地校验）
- [ ] 给某角色填「口癖」和「禁用言行」，**手动**写一段违反它的文字 → 守门应报出违规。
- [ ] 设定事实（如"主角左眼有疤"），再写一段颠覆它的文字 → 账本/守门应提示冲突。

### A7. 崩溃与日志
- [ ] 随便触发一个错误（如填个无效的 API Key 跑一次）→ **不白屏**，日志面板出现 ERROR 记录且提示可读。

## C 组：需要外部服务

- [ ] **语义嵌入 RAG** —— 配了 bge-m3 后，召回标签应从「离线词向量」变为 **「语义嵌入」**，且近义/改写前情也能命中。
- [ ] **HTTP 桥接（`127.0.0.1:18791`）** —— 应用已打开时执行：
  ```
  curl.exe http://127.0.0.1:18791/status
  curl.exe -X POST http://127.0.0.1:18791/wanxiang/create -H "Content-Type: application/json" -d '{"world_type":"xianxia","seed":42,"ticks":0}'
  ```
  判定：`create` 返回的 `info` 必须是**非空对象**。若返回 `{}` 说明桥接没接上引擎。
  （CMD 下 JSON 内引号需写成 `{\"world_type\":\"xianxia\"}`）
