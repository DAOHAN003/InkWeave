## 一、市场分析

| | 仙侠 | 玄幻 |
|--|------|------|
| **世界观** | 东方修仙 / 道法自然 | 架空大陆 / 万族林立 |
| **等级** | 练气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫 → 大乘 | 斗者 → 斗师 → 斗灵 → 斗王 → 斗皇 → 斗宗 → 斗尊 → 斗圣 → 斗帝 |
| **读者** | 偏文青 / 古风爱好者 | 偏爽文 / 热血读者 |
| **番茄热度** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

**推荐：仙侠 + 玄幻融合** —— 用仙侠的修炼体系 + 玄幻的爽文节奏

## 二、等级体系设计

### 修炼境界（9 大境界 × 9 小层）

```
凡人 → 练气（1-9 层）→ 筑基（1-9 层）→ 金丹 → 元婴 → 化神 → 合体 → 渡劫 → 大乘 → 飞升

每个大境界的突破 = 一个大爽点
每个小层的突破 = 一个小爽点
主角比同龄人快 3-5 个大境界 = 持续碾压感
```

### 战力辅助系统

```
丹药：回复 / 增幅 / 突破（炼丹是持续的爽点来源）
法宝：攻击 / 防御 / 辅助（收集法宝 = 捡宝爽点）
功法：基础 / 高级 / 天级 / 圣级 / 神级（功法升级 = 战力暴涨）
血脉：普通 / 变异 / 远古 / 混沌（血脉觉醒 = 身份揭秘）
```

## 三、最火的 5 种仙侠金手指

### 1. 混沌鼎 / 太古炉 — 炼丹无敌 + 炼化万物

> **爽点**：别人炼废的丹你一炉成，还多出三颗

### 2. 天道之眼 / 鉴宝瞳 — 看穿一切（宝物品质 / 对手弱点 / 功法破绽）

> **爽点**：拍卖会上别人出天价买废物，你花一文钱捡到神器

### 3. 轮回重生 — 带着前世记忆和修为重生

> **爽点**：知道所有机缘在哪 / 知道谁会背叛 / 提前布局

### 4. 吞噬体质 — 吞噬别人的修为 / 血脉 / 功法

> **爽点**：打败对手后还能吸收对方实力

### 5. 时间加速空间 — 外面 1 天 = 里面 1 年

> **爽点**：闭关 3 天出来实力暴涨，别人以为你开挂

**推荐组合：轮回重生 + 混沌体质**

- 重生提供"先知" → 知道机缘在哪
- 混沌体质提供"碾压" → 修炼速度 10 倍
- 两个金手指互相配合不冲突

## 四、开头设计

### 第 1 章公式

```
开篇 100 字：主角在最惨的时刻（被逐出宗门 / 被退婚 / 被杀）
200 字      ：重生 / 觉醒（回到过去 / 金手指激活）
500 字      ：第一个爽点（用先知躲过陷害 / 用新能力碾压欺负自己的人）
章末        ：更大的机会出现（发现一个前世不知道的机缘）
```

### 示例开头

> "陈风看着自己胸口的剑痕，笑了。  
> 这是第二次了。  
> 上一世，他被师兄一剑穿心，死在了天玄宗的后山。  
> 这一世——  
> 他低头看了看自己的手。十六岁的手。年轻的、没有老茧的、还没有握过剑的手。  
> 混沌珠在丹田里缓缓转动。  
> 很好。  
> 这一次，他要让所有人知道，什么叫——天才。"

## 五、势力格局

```
小世界：宗门（天玄宗 / 剑灵宗 / 丹霞宗）+ 家族（陈家 / 赵家 / 王家）
中世界：帝国 / 圣地 / 隐世势力
大世界：上界 / 仙界 / 神界

主角的路线：
  宗门内弟子 → 宗门天才 → 参加大比 → 进入圣地 → 飞升上界

每个层级都有：
  新的敌人（更强的天才）
  新的机缘（更强的功法 / 法宝）
  新的美女（更高级的）
  新的打脸对象
```

## 六、万象引擎适配

### 现有万象引擎改造方案

```
现有万象引擎：117 个历史天骄 + 百姓
改造成仙侠：

entity 类型改造：
  天骄 → 各宗门天才（有境界 / 功法 / 血脉属性）
  百姓 → 普通弟子 / 散修
  新增：宗门长老 / 家族族长 / 魔道修士

碰撞类型改造：
  战争碰撞 → 宗门大比 / 秘境争夺 / 天才对决
  政治碰撞 → 宗门联盟 / 背叛 / 阴谋
  死亡碰撞 → 陨落 / 突破失败 / 被暗杀

新增属性：
  境界（练气 ~ 大乘）
  功法（品级 + 类型）
  法宝（品级 + 效果）
  血脉（类型 + 觉醒度）

模拟输出：
  每个时间段谁突破了 / 谁打败了谁 / 哪个宗门崛起 / 哪个天才陨落
  → 编排成大纲 → 分身写
```

### 万象仙侠世界模板

```
世界：苍穹大陆
9 大宗门（对应 9 个修炼境界各有所长）
3 大帝国（人族 / 妖族 / 魔族）
100+ 天才角色（各宗门弟子）
500+ 普通角色（散修 / 商人 / 百姓）

主角：陈风，天玄宗外门弟子，废材体质
金手指：重生 + 混沌珠（前世大乘期强者记忆）

模拟 30000 天（约 82 年修仙生涯）：
  0-5 年  ：宗门内崛起
  5-15 年 ：宗门大比称霸
  15-30 年：圣地修炼
  30-50 年：大陆争霸
  50-82 年：渡劫飞升
```

## 七、前 10 章大纲

```
第 1 章：重生（大乘期强者陈风被暗算 → 重生回 16 岁 → 混沌珠激活 → 天玄宗外门废材弟子）
第 2 章：第一个打脸（外门考核 → 别人嘲笑废材 → 一拳碾压外门第一 → 长老震惊）
第 3 章：混沌珠的秘密（发现前世不知道的功法 → 修炼速度暴增 → 一夜突破练气三层）
第 4 章：捡宝（去后山找前世记忆中的灵药 → 发现一个远古洞府 → 获得第一件法宝）
第 5 章：打脸内门师兄（内门弟子来欺负外门 → 陈风一招制敌 → "你确定你是练气期？"）
第 6 章：引起长老注意（长老暗中观察 → 决定收为亲传 → 但陈风拒绝了 → "我要自己选师父"）
第 7 章：宗门试炼开始（秘境开启 → 100 个弟子进入 → 陈风的目标：前世错过的混沌灵根）
第 8 章：秘境第一战（遇到内门天才赵天 → 激战 → 越级碾压 → 赵天跪了）
第 9 章：找到混沌灵根（秘境深处 → 远古阵法 → 用前世记忆破阵 → 获得混沌灵根 → 体质蜕变）
第 10 章：秘境出来（所有人震惊 → 陈风从练气直接突破到筑基 → 宗主亲自来见 → "百年一遇的天才"）
```

## 八、我们的核心优势

```
别人的仙侠爽文：套路化 + 文笔差 + AI 味重

我们的仙侠爽文：

1. 万象引擎模拟 → 世界"活"的，不是死的设定
   天才之间真的在碰撞 / 竞争 / 成长 / 陨落

2. 顶级文笔 → 战斗场景有质感
   不是"一剑劈出，威力惊人"
   而是"剑锋切入空气的一瞬间，他听见了风被撕裂的声音。不是呼啸，是嘶——像布被扯开。剑尖的寒气从手腕传到肩膀，冷的，麻的。"

3. 感官密集 → 修炼 / 战斗 / 丹药都有身体感受
   不是"他突破了练气三层"
   而是"丹田里的灵气像一锅沸腾的水，从下往上涌。热的。烫的。从丹田烫到胸口，从胸口烫到喉咙。他咬住牙，牙根发酸。然后——'咔'。像什么东西碎了。不是碎，是开了。一扇门，在身体里面，开了。"
```
