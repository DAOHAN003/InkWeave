# 番茄爆款爽文研究报告

---

## 一、爽文核心机制

### 10 种爽点（每章至少 1 个）

| # | 类型 | 说明 |
|---|------|------|
| 1 | **打脸** | 看不起主角的人被现实打脸（最爽） |
| 2 | **逆袭** | 从最底层一步步碾压（持续爽） |
| 3 | **装逼** | 扮猪吃老虎，关键时刻亮身份 |
| 4 | **升级** | 实力突破 / 获得新能力 / 解锁新技能 |
| 5 | **捡宝** | 获得神器 / 秘籍 / 传承 / 系统奖励 |
| 6 | **救美** | 在绝境中救下美女 / 获得好感 |
| 7 | **碾压** | 以绝对实力碾压对手（读者代入感最强） |
| 8 | **复仇** | 被欺负后强势回击 |
| 9 | **震惊** | 所有人被主角实力 / 身份震惊 |
| 10 | **认主** | 神兽 / 神器 / 大佬主动认主角 |

---

### 钩子设计（3 种）

```
每章最后 3 行必须有钩子，让读者忍不住翻下一章。

1. 悬念型："门外站着一个人。那个人，不应该出现在这里。"
2. 危机型："他的灵力，在这一刻，彻底枯竭了。"
3. 反转型："他笑了。因为他等的，就是这一刻。"
```

---

### 金手指设定原则

```
1. 有限制（不能无敌，要有代价）
2. 可升级（跟主角一起成长）
3. 有独特性（别人没有的）
4. 能制造爽点（每次使用都有爽感）

好的金手指：系统 / 鉴宝之眼 / 时间回溯 / 读心术 / 炼丹天赋
差的金手指：直接无敌 / 一拳打爆星球（没有成长空间）
```

## 二、番茄热门品类（2025-2026）

| 品类 | 热度 | 适合 AI 写 | 原因 |
|------|------|-----------|------|
| **都市系统流** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 现代背景好写 + 系统提供结构化升级 |
| **玄幻升级** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 战斗场景模板化 + 等级体系清晰 |
| **重生逆袭** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 主角知道未来走向好安排剧情 |
| **赘婿打脸** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 套路固定 + 打脸场景好写 |
| **神医 / 神豪** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 场景丰富 + 爽点密集 |

**推荐：都市 + 系统流 + 重生**

- 现代背景不需要构建复杂世界观
- 系统提供结构化的升级路线（万象引擎可以模拟）
- 重生给主角合理的"先知"能力
- 打脸场景容易写且读者最爱看

## 三、开头黄金 3 章

### 第 1 章必须做到

```
前 100 字：制造冲突（主角被欺负 / 被看不起 / 遭遇危机）
前 500 字：金手指激活（系统觉醒 / 获得传承 / 重生回来）
前 1000 字：第一个小爽点（用金手指化解危机 / 打脸一个小人物）
章末：更大的危机或更大的机会（钩子）

公式：
  惨（被欺负）→ 转（金手指来了）→ 爽（小试牛刀）→ 钩（更大的事来了）
```

### 前 3 章必须完成

```
第 1 章：主角出场 + 金手指激活 + 第一个爽点
第 2 章：金手指的规则说明 + 第二个爽点（更大）
第 3 章：主线冲突建立 + 第一个打脸场景 + 长线钩子

3 章内必须让读者知道：
1. 主角是谁（身份 / 处境）
2. 金手指是什么（能力 / 限制）
3. 主线目标是什么（要做什么）
4. 第一个敌人是谁（冲突对象）
```

## 四、节奏控制

### 爽文节奏公式

```
每章（2000-3000 字）  ：至少 1 个爽点 + 1 个钩子
每 5 章             ：1 个小高潮（打脸一个小反派）
每 20 章            ：1 个中高潮（解决一个大危机 / 升一个大级）
每 50 章            ：1 个大高潮（打脸一个大反派 / 身份大揭露）
每 100 章           ：1 个超级高潮（逆天改命 / 碾压 boss）

低谷规则：
  低谷不超过 2 章（读者耐心有限）
  低谷中也要有小爽点（不能纯惨）
  低谷后的爽点要加倍（压得越低弹得越高）
```

### 日更策略

```
番茄最优：日更 4000-6000 字（2-3 章）
最低底线：日更 2000 字（1 章）
存稿策略：先存 30-50 章再开更（保证稳定日更 1 个月）
```

## 五、赚钱策略

```
广告分成 = 阅读量 × 完读率 × 广告单价

关键指标：
  完读率 > 30%（读者读完一章的比例）
  追读率 > 10%（读者持续追更的比例）
  字数 > 100 万（越长越赚）

什么样的书赚钱：
  1. 日更稳定（算法喜欢稳定更新的书）
  2. 章末钩子强（完读率高）
  3. 爽点密集（追读率高）
  4. 超长篇（广告展示次数多）
```

## 六、AI 写爽文的优势和陷阱

### 优势

```
1. 日更速度碾压人类（我们能日更 6 万字）
2. 万象引擎生成的世界数据保证剧情不崩
3. 知识库积累的文笔质量远超普通网文
4. 永不断更（AI 不会生病 / 不会拖延）
```

### 陷阱

```
1. AI 倾向写"叙述"不写"场景" → 必须写具体场景不写概述
2. AI 的爽感不够"爽" → 必须在 prompt 里强调"读者要爽"
3. AI 容易重复套路 → 意象 / 打脸方式必须换花样
4. AI 的对话太书面 → 爽文对话要短、要狠、要装逼
```

### 去 AI 味（爽文版）

```
爽文的去 AI 味和文学向不同：
  文学向：要脏感官 / 要克制 / 要留白
  爽文  ：要爽 / 要快 / 要直接 / 要装逼

爽文去 AI 味重点：
  1. 对话要短要狠："你算什么东西？"（不要"他感到对方的实力不容小觑"）
  2. 打脸要具体：写脸的表情变化（不要"众人震惊"）
  3. 升级要有仪式感：写突破的身体感受（不要"他的实力提升了"）
  4. 装逼要有反差：先被看不起 → 再一击碾压
```

## 七、爆款模板

### 推荐方向：都市重生 + 系统

```
世界观：现代都市（不需要构建）
主角  ：30 岁失败者重生回 18 岁高三
金手指：万象系统（预知未来 + 技能学习 + 任务奖励）
主线  ：重活一世，弥补遗憾，走上巅峰

为什么选这个：
  - 重生 = 合理的先知（知道股票 / 商机 / 考题）
  - 系统 = 结构化升级（万象引擎可以模拟）
  - 都市 = 读者代入感强
  - 18 岁高三 = 最大的读者群体
```

### 前 10 章大纲

```
第 1 章：重生（30 岁失败者被车撞 → 醒来发现回到 18 岁高三 → 系统激活）
第 2 章：第一个打脸（被同学嘲笑成绩差 → 考试全对 → 老师震惊）
第 3 章：系统说明（任务 / 奖励 / 升级 / 限制）+ 第一个任务
第 4 章：赚第一桶金（知道彩票号码 / 股票 / 商机）
第 5 章：打脸前女友 / 白月光的现男友
第 6 章：第一次实力展示（学了格斗技能打跑校霸）
第 7 章：认识第一个美女配角（被主角的改变吸引）
第 8 章：第一个大危机（前世害自己的人提前出现）
第 9 章：化解危机 + 获得新能力
第 10 章：高考前的大爽点（模考全校第一 + 体育碾压 + 被校花注意）
```

## 八、万象引擎适配方案

```
entity 类型：
  主角（1 个）— 有系统加持
  美女角色（3-5 个）— 不同性格
  反派（分级：小反派 / 中反派 / 大 boss）
  配角（朋友 / 家人 / 老师）

碰撞类型：
  打脸碰撞（主角 vs 反派）
  感情碰撞（主角 vs 美女）
  升级事件（系统任务完成）
  危机事件（反派设局）

模拟输出：
  每个时间段有什么碰撞 → 编排成大纲 → 分身写
```
