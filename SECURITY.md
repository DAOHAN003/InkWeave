# Security policy

The security helpers are experimental and are **not** a substitute for OS isolation. See [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).

Do not post exploitable details in a public issue. Use GitHub's **Report a vulnerability** / private Security Advisory flow for this repository. Include the affected path, impact, reproduction steps and suggested mitigation. If private reporting is not enabled, contact the maintainer through the GitHub profile and ask for a private channel.

We will acknowledge reports when practical and coordinate disclosure after a fix or mitigation is available. No response-time SLA is promised at this stage.
